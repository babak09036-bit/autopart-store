# اتوپارت — فروشگاه اینترنتی لوازم جانبی خودرو

فروشگاه نمایشی فارسی و راست‌چین، ساخته‌شده فقط با HTML، CSS و JavaScript خام؛ بدون فریم‌ورک، CDN یا وابستگی خارجی.

- ۱۰ صفحه: خانه، محصولات، جزئیات محصول، دسته‌بندی، جستجو، سبد خرید، علاقه‌مندی‌ها، ورود، پیگیری سفارش، تماس با ما
- ۴۸ محصول با تصویر SVG اختصاصی، ۱۰ دسته‌بندی، ۱۰ برند نمونه
- سبد خرید، علاقه‌مندی‌ها و سفارش‌ها در LocalStorage مرورگر ذخیره می‌شوند
- کدهای نمونه پیگیری سفارش: `AP-100245`، `AP-100318`، `AP-100402`

اجرای محلی: پوشه را روی هر وب‌سرور ساده (مثلاً XAMPP) قرار دهید و `index.html` را باز کنید.

> همه اطلاعات، برندها، قیمت‌ها و نظرات نمایشی هستند و هیچ پرداخت واقعی انجام نمی‌شود.
